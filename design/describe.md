# 描述协定

由于原版游戏的正式描述对于我来说比较麻烦，为了方便我描述我的设计，我会用自己的一套描述。当你检查我的设计时，应以我的描述规则为准，我会在下文详细说明怎么把我的描述转化为正式描述，如果我下文的转化规则有歧义或矛盾，请告知我。如果有遗漏并且影响你读我当前的设计，请立刻告诉我。
注意，最终你写进代码里的应该是**正式描述**

| 我的描述 | 正式描述/含义 |
| :---: | :---: |
| [任意中文内容] | 表示一个关键词，你应该检查方括号中的内容是否是官方的一个内置关键词或本mod增加的一个关键词 |
| [E] | 能量图标 |

## 一些你关于正式描述的回答

在 STS2 里，方括号 `[活力]` 是《杀戮尖塔1》的写法，2 代不再这么写。2 代的文本规则大致是这样：

**1. 数值（会变或要显示升级差值的）用动态变量占位符**
- 伤害：`{Damage}`，格挡：`{Block}`，卡牌数：`{Cards}`，血量等各自有对应变量
- 想显示「升级后数值变化」就加 `:diff()`，例如 `{Damage:diff()}`、`{Block:diff()}`

**2. 能量用图标占位符，不是写「[能量]」**
- 例如「下张牌耗能减少 1」写 `{energyPrefix:energyIcons(1)}`

**3. 强调 / 着色用 BBCode，不是方括号**
- `[blue]4[/blue]`、`[pink]...[/pink]` 这类

**4. 内置关键词（活力/格挡/力量等）直接用游戏官方中文名写进正文**
- 不用方括号，也不用自己定义；这些词已经存在于游戏自己的关键词表里，只要名字和游戏官方翻译一致，游戏会自动给它们加图标/悬浮提示
- 只有你**新造**的关键词才需要单独注册到 `card_keywords` 表，并给它一个 owned id（形如 `FOREFINGER_KEYWORD_XXX`）

**5. 固定数值直接写数字**，只有需要随状态变化的才用 `{X}`

拿「指令加护」举例，你原来写：

```
1、获得4[活力]
2、获得4[格挡]
3、抽两张牌
4、获得1[能量]
```

按 2 代习惯应该改成（数字统一用阿拉伯数字）：

```
回合开始时，等概率触发下列效果之一：
1. 获得 4 层活力
2. 获得 4 点格挡
3. 抽 2 张牌
4. 获得 1 点能量
```

其中第 4 条如果想要显示能量图标，可以写成「获得 1 点能量」或直接嵌入 `{energyPrefix:energyIcons(1)}`。

一个需要你拍板/确认的点：**「活力 / 格挡 / 能量 / 力量」这几个词，最终要和游戏官方中文翻译一致**，否则游戏不会自动关联图标和悬浮提示。游戏主资源包（`SlayTheSpire2.pck`）是加密的，我暂时读不到里面的官方中文本地化表，所以这几个词的中文名需要你在游戏里对照一下，或者我按英文 `Vigor / Block / Energy / Strength` 来写、中文名后面再对齐。你希望用哪种方式？
