# 描述协定

由于原版游戏的正式描述对于我来说比较麻烦，为了方便我描述我的设计，我会用自己的一套描述。当你检查我的设计时，应以我的描述规则为准，我会在下文详细说明怎么把我的描述转化为正式描述，如果我下文的转化规则有歧义或矛盾，请告知我。如果有遗漏并且影响你读我当前的设计，请立刻告诉我。
注意，最终你写进代码里的应该是**正式描述**

| 我的描述 | 正式描述/含义 |
| :---: | :---: |
| [任意中文内容] | 表示一个关键词，你应该检查方括号中的内容是否是官方的一个内置关键词或本mod增加的一个关键词 |
| [E] | 能量图标 |
| {C} | 手牌数（显然不包括运行区的） |

卡牌、遗物的ID以其英文名为准，用大驼峰命名规则加上Forefinger前缀
